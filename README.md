# ヤマダ エデュケーション事業部 HP

CEOキッズアカデミー 加盟パートナー募集サイト（静的HTML）。

公開URL: https://livmakers.github.io/yamada-edu-hp/

写真: Unsplash

## 採用サイト（/recruit/）
- `recruit/index.html` 採用トップ、`recruit/jobs/*.html` 職種別ページ（求人の構造化データ JobPosting 付き）
- `privacy.html` プライバシーポリシー（加盟問い合わせ・採用応募の両方）
- `sitemap.xml` Google Search Console に登録して使う
- オレンジの「要確認」表示（class="ph"）は、未確定の条件の仮置き。確定したら差し替える
- 職種や募集条件を変えるときは、採用トップと4つの職種ページを同じ内容にそろえて更新する
